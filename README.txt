موقع هدية رومانسية لخلوده وكوكو ❤️

الملفات:
- index.html: الموقع كامل (HTML + CSS + JavaScript في ملف واحد).

تشغيله من موبايل أندرويد:
1. نزّل ملف ZIP وفك الضغط عنه من تطبيق "ملفاتي".
2. افتح index.html باستخدام متصفح Chrome. لو لم يفتح مباشرة، استخدم محرر HTML على الهاتف أو انشره بالخطوات التالية.

نشر مجاني عبر GitHub Pages:
1. افتح https://github.com من Chrome وأنشئ حسابًا أو سجّل الدخول.
2. أنشئ مستودعًا جديدًا (New repository)، واجعله Public، وسمّه مثلًا koko-love.
3. ارفع ملف index.html إلى المستودع باستخدام Add file > Upload files ثم Commit changes.
4. افتح Settings > Pages.
5. تحت Build and deployment اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
6. انتظر قليلًا حتى يظهر رابط الموقع في صفحة Pages. افتحه وجرب كلمة المرور 942006.

تعديل الأغنية والصورة:
- اختيار الأغنية أو الصورة داخل الموقع حاليًا للمعاينة على نفس الجهاز فقط.
- لكي تظهر الصورة/الأغنية لكل من يفتح الموقع، أضف الملفات إلى المستودع ثم عدّل HTML ليشير إلى أسماء الملفات.
- استخدم فقط صورًا وأغانٍ تملكها أو لديك إذن باستخدامها.

تنبيه:
كلمة المرور في هذا النموذج موجودة داخل JavaScript، لذلك هي قفل لطيف وليست حماية أمنية؛ أي شخص يستطيع فحص الكود واكتشافها. لا تضع معلومات خاصة أو حساسة في الموقع.
